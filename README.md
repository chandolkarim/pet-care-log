# 반려동물 돌봄 기록

**밥과 약을 줬는지 헷갈릴 때 여는 한 화면.** 가족이 구글 시트에 한 줄씩 기록하면, 페이지가 구글 시트를 읽어 항목별 마지막 기록, 중복 투약 경고, 빠뜨린 일정을 보여 줍니다. 5주차 `시트 → CSV → Actions → Pages` 흐름을 바탕으로 만들었고, Python 표준 라이브러리만 씁니다.

```text
가족이 시트에 기록 → 구글 시트(일정 탭 · 기록 탭) → 웹에 게시(CSV)
  ├─ 지금 상태 페이지: 열 때마다 브라우저가 CSV를 읽음(반영까지 최대 5분)
  └─ GitHub Actions(푸시 · 버튼 · 매일 08:17): main.py가 검사 → 페이지 생성 → Pages 배포
```

## 파일 역할

| 파일 | 역할 |
|---|---|
| `main.py` | 두 CSV 읽기, 열·값 검사(문제가 있으면 이유와 행 번호를 출력하고 멈춤), 페이지 생성 |
| `page.html` | 지금 상태 화면의 틀. 상태 계산은 브라우저에서 한국시간 기준으로 합니다 |
| `sample_schedule.csv` · `sample_log.csv` | 시트와 같은 열 구조의 샘플. 로컬 실행 때 날짜를 오늘로 옮겨 씁니다 |
| `site.json` | 페이지 제목과 설명 |
| `.github/workflows/pet_care_site.yml` | 저장소 변수 전달, 매일 검사, Pages 배포 |

## 1. 로컬에서 먼저 실행

```bash
python3 main.py --output _site/index.html
open _site/index.html
```

샘플에는 코코의 심장약을 엄마와 민수가 18분 간격으로 두 번 준 기록이 들어 있어, 빨간 중복 경고가 보입니다.

## 2. 구글 시트 만들기

새 스프레드시트에 탭 두 개를 둡니다.

**일정 탭** · 1행 열 이름을 그대로 적습니다(순서는 바뀌어도 됨). `sample_schedule.csv`를 가져와도 됩니다.

| 열 | 필수 | 내용 |
|---|---|---|
| 반려동물 | 필수 | 이름 |
| 항목 | 필수 | 예: 아침밥, 심장약 |
| 종류 | 필수 | `밥` 또는 `약` |
| 시각 | 필수 | `HH:MM`. 여러 번이면 쉼표로 `08:00,20:00` |
| 양 | 선택 | 예: 1알, 40g |
| 최소간격 | 약은 필수 | 시간 단위 숫자. 이보다 빨리 다시 기록되면 중복 경고 |
| 시작일 · 종료일 | 선택 | `YYYY-MM-DD`. 비우면 계속 적용 |
| 사용 | 필수 | `Y`인 행만 적용 |
| 메모 | 선택 | 카드에 함께 표시 |

**기록 탭** · 밥·약을 줄 때마다 한 줄씩 직접 적습니다. A1에 아래 줄을 붙여 넣고 **데이터 → 텍스트를 열로 분할**을 누릅니다.

```text
타임스탬프,실제 시각,누가,반려동물,항목,양,체중,증상,메모
```

| 열 | 필수 | 내용 |
|---|---|---|
| 타임스탬프 | 필수 | 준 시각. `⌘ + ⌥ + ⇧ + ;`(Windows `Ctrl + Alt + Shift + ;`)로 지금 날짜·시각 입력. `2026-09-30 15:12`처럼 적어도 됨 |
| 실제 시각 | 선택 | 나중에 몰아 적을 때만 `HH:MM`. 비우면 타임스탬프 사용 |
| 누가 | 필수 | 가족 호칭(엄마, 민수) |
| 반려동물 | 필수 | 일정 탭의 이름과 똑같이 |
| 항목 | 필수 | 일정 탭의 항목, 또는 `증상`, `체중` |
| 양 · 체중 · 증상 · 메모 | 선택 | 체중은 kg 숫자, 증상은 `구토, 설사`처럼 |

오타를 막으려면 누가·반려동물·항목 열을 선택하고 **데이터 → 데이터 확인 → 드롭다운**으로 선택지를 정해 둡니다.

## 3. (선택) 나중에 구글 폼으로 바꾸기

폰으로 더 빨리 기록하고 싶으면, 시트에서 **도구 → 새 양식**으로 폼을 만듭니다. 질문 제목을 기록 탭 열 이름(누가, 반려동물, 항목, 실제 시각, 양, 체중, 증상, 메모)과 똑같이 적으면 응답 탭에 타임스탬프가 자동으로 찍힙니다. 그 응답 탭을 CSV로 게시해 `LOG_CSV_URL`을 바꾸고, 폼 링크를 `FORM_URL`에 넣으면 '+ 기록하기' 버튼이 생깁니다.

## 4. 게시하고 저장소에 연결하기

1. 파일 → 공유 → **웹에 게시**에서 **일정 탭**을 CSV로 게시하고 주소를 복사합니다. **기록 탭**도 같은 방법으로 주소를 받습니다.
2. 저장소 Settings → Secrets and variables → Actions → **Variables**에 세 개를 등록합니다.
   - `SCHEDULE_CSV_URL`: 일정 탭 CSV 주소
   - `LOG_CSV_URL`: 기록 탭 CSV 주소
   - `RECORD_URL`: 시트 기록 탭의 편집 주소(`…/edit#gid=<기록 탭 번호>`). '+ 기록하기' 버튼이 이 탭을 엽니다
   - `FORM_URL`: 3절의 폼을 쓸 때만. `RECORD_URL`이 있으면 그쪽이 먼저입니다
3. Settings → Pages → Source를 **GitHub Actions**로 둡니다.
4. Actions → Pet Care Site → **Run workflow**를 누릅니다.

## 5. 검증할 것

| 상황 | 해 보는 방법 | 기대 결과 |
|---|---|---|
| 정상 기록 | 기록 탭에 아침밥 한 줄 추가 | 5분 안에 카드가 "완료 · 누가"로 바뀜 |
| 중복 투약 | 같은 약을 두 사람이 10분 간격으로 기록 | 빨간 경고에 두 사람과 시각 표시 |
| 빠뜨림 | 일정 시각 + 30분까지 기록 안 함 | "n분 지남" 경고 |
| 투약 기간 끝 | 종료일을 어제로 바꿈 | 그 약이 카드에서 사라짐 |
| 바뀐 열 | 일정 탭 열 이름 하나 바꾸고 실행 | build 실패, 빠진 열과 현재 열 출력 |
| 잘못된 시각 | 시각에 `8시`라고 적음 | build 실패, 행 번호와 이유 출력 |
| 몰아서 입력 | 실제 시각에 2시간 전 시각을 적음 | 타임스탬프가 아닌 실제 시각으로 계산 |
| 휴대전화 폭 | 폰으로 공개 주소 열기 | 가로 넘침 없음 |

## 공개 범위와 안전

- 웹에 게시한 CSV와 페이지는 **주소를 아는 누구나** 볼 수 있습니다. 집 주소, 전화번호, 실명, 진료비는 적지 않고, 누가 열에는 호칭만 씁니다.
- '+ 기록하기'에 들어가는 편집 주소는 링크만으로 열리지 않습니다. 시트 **공유**에서 편집자로 추가한 가족만 열 수 있으니, 시트를 '링크가 있는 모든 사용자'로 공유하지 마세요. 페이지 주소는 가족에게만 알립니다. 검색 엔진에 나오지 않도록 `noindex`를 넣었습니다.
- **수의사 처방을 대신하지 않습니다.** 약의 양과 간격은 처방전 값을 사람이 일정 탭에 적습니다.
